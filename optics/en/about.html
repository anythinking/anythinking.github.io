About this map

I put this together while studying what structures optical computing is built from, which devices those structures are made of, and which layers it passes through from physics up to accelerators. The structure figures can be moved by hand, and numbers are marked as either values reported in the source paper or values I calculated myself.

This map was made while learning, so it may contain mistakes. If you find one, please let me know.
